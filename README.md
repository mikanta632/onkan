# 音感トレーニング

発声・相対音感・絶対音感を練習できる Web アプリです。
iPhone の Safari での利用を想定しています。HTML / CSS / 素の JavaScript だけで動き、ビルドは不要です。

## 使い方

練習タブの上部で「発声」「相対音感」「絶対音感」を切り替えます。どのモードでも、ボタンは次の 3 つです。

- **終了**：解答中の問題を記録せずに取りやめ、音とマイクを止めます。
- **もう一度**：お手本を聞き直します。解答中に押すと、記録はやり直しになります。判定後に押すと、答え合わせ用に正解の音を鳴らします。
- **次の問題**：解答中に押すと、不正解として記録してから次へ進みます。

### 発声練習

発声練習には「1音」「音程」「フレーズ」の 3 種類があります。どれも、声を出し始めた時点から記録を始めます。マイクを使うのは、声を待っている間と記録中だけです。お手本を鳴らしている間と、判定が出たあとはマイクを止めます。

- **1音**：お手本と同じ高さで「アー」と歌います。記録時間（初期値 2 秒）のうち、お手本との差が ±30 セント以内だった時間の割合が 70% 以上なら正解です。
- **音程**：基準音を聞いて、「ド（C4）から長3度上」のように指定された音程の音を歌います。判定は「1音」と同じです。出題する音程と向きは、相対音感の設定を使います。
- **フレーズ**：短いフレーズを聞いて、同じテンポで歌い返します。声を出し始めた時点から 1 音ずつ時間の枠を区切り、各音の枠の中で合っていた割合で 1 音ずつ合否を出します。全部の音が合格なら正解です。画面には、お手本の音を帯で、自分の声を線で重ねて表示します。

#### フレーズの出題

出題の前に主和音（長調はドミソ、短調はラドミ）を鳴らして調を示します。答え合わせでは、フレーズを移動ドの階名（例：ド・ミ・ソ）で表示します。鍵盤で答える相対音感より取り組みやすく、調の中で音の動きを覚える練習になります。

フレーズ画面の上部で、出題の種類を切り替えます。

- **レベル**：2 音・隣の音だけから始めて、3 問続けて正解すると次のレベルへ上がります（全 12 段階）。3 問続けて外すと 1 つ下がります。
- **ランダム**：設定した音の数（2〜8 音）・跳び方（隣の音〜8度）・調で作ります。
- **型**：音階・主和音・導音から主音へなど、曲によく出る音の動きです。
- **曲**：童謡・民謡・クラシックの有名な一節です（作曲者の没後 70 年を過ぎた曲と民謡・古謡だけを使い、歌詞は載せていません）。音の長さも曲に合わせます。

設定の「出題のしかた」を「階名を見て歌う」にすると、お手本は鳴らさず、主和音と階名だけを手がかりに歌います（視唱の練習）。判定後の「もう一度」でお手本を聞けます。

歌ったフレーズは、音程（前の音からの動き。例：長3度上）ごとに正解率を記録します。「記録」タブで苦手な順に見られます。「苦手な音程を多めに出す」をオンにすると、レベル・ランダムで外すことの多い音程が出やすくなります。

判定後は、出だし（最初の 0.2 秒）のずれと後半のずれを表示します（例：「出だし +45 → 後半 +5 セント」）。数字が両方とも小さければ、最初から高さを当てられています。出だしだけ大きければ、聞きながら直しています。
「1音」「音程」では、記録した音程の動きもグラフで見られます。緑は合っていた部分、オレンジは高すぎ、青は低すぎです。

初期設定では、オクターブ違いも正解になります（お手本が E4 のとき、E3 や E5 で歌っても正解）。判定条件は、お手本の下に表示されます。10 秒たっても声が出なければ不正解になります。

### 相対音感

基準音と 2 つ目の音が続けて鳴ります。2 つ目の音を鍵盤で答えます。基準音の鍵盤には「基準」の印が付きます。
答えたあとは、正解の音と基準からの音程（例：完全5度上）が表示されます。鍵盤をタップすると、その音を聞いて確かめられます。

### 絶対音感

基準音なしで 1 音だけ鳴ります。その音名を鍵盤で答えます（オクターブは問いません）。

### 設定と記録

「設定」タブでは、次の項目をモードごとに変えられます。

- 発声練習：出題範囲、合っているとみなす幅、記録する時間、正解に必要な割合、声を出すまでの制限時間、オクターブ違い
- フレーズ：出題のしかた（聞いて歌う・階名を見て歌う）、主和音を先に鳴らすか、レベル、苦手な音程を多めに出すか、テンポ、調（長調・短調・両方）、ランダムの音の数と跳び方
- 相対音感：出題する音程（13 種類から複数選択）、2 つ目の音の向き（上行・下行・両方）
- 絶対音感：使う音（白鍵のみ・12 音すべて）、出題範囲

日ごとの挑戦数と正解率は、「記録」タブで練習の種類別に見られます（発声練習は 1音・音程・フレーズを分けて記録します）。フレーズの音程別の正解率も同じタブにあります。記録はその端末のブラウザ（localStorage）にだけ保存されます。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作ります（例：`onkan`）。
2. このフォルダの中身をプッシュします。

   ```bash
   git add .
   git commit -m "最初の版"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/onkan.git
   git push -u origin main
   ```

3. リポジトリの **Settings → Pages** を開き、**Source** を「Deploy from a branch」、**Branch** を `main` と `/ (root)` にして保存します。
4. 1〜2 分待つと `https://<ユーザー名>.github.io/onkan/` で公開されます。iPhone の Safari でこの URL を開いてください。

### 変更を公開するとき

1. `js/version.js` の `APP_VERSION` を上げます（例：`1.2.0` → `1.3.0`）。
2. ファイルを追加・改名した場合は、`js/updater.js` の `ASSETS` にも書き足します。
3. コミットして `main` に push します。1〜2 分で Pages に反映されます。

アプリは起動時とアプリに戻ったときに公開中のバージョンを確かめ、新しければ画面上部に「新しいバージョンがあります」と表示します。
設定画面の「最新版を確認して更新」からも、手動で更新できます。どちらも全ファイルを取り直してから読み込み直すので、ホーム画面から起動している場合でも最新版になります。

マイクを使うには HTTPS が必要です。GitHub Pages は HTTPS で配信されるので、追加の設定はいりません。
Safari の共有メニューから「ホーム画面に追加」すると、アプリのように起動できます。

## 手元で動かす

ES Modules を使っているため、`index.html` をダブルクリックして開く（`file://`）と動きません。簡単なサーバーを立ててください。

```bash
python -m http.server 8000
```

PC のブラウザで `http://localhost:8000` を開きます（`localhost` ならマイクが使えます）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面（練習・記録・設定の 3 タブ） |
| `css/style.css` | スマホ縦画面向けのスタイル |
| `js/main.js` | タブ切り替え、設定フォーム、記録一覧、モードの登録 |
| `js/audio-engine.js` | AudioContext とマイクの管理（タップを起点に開始） |
| `js/tone-player.js` | お手本の再生（オシレーター） |
| `js/pitch-detector.js` | 音高推定（YIN 法）。DOM・Web Audio に依存しない純粋な関数 |
| `js/pitch-tracker.js` | マイク入力の読み取り、推定、中央値による平滑化 |
| `js/note-utils.js` | 周波数・MIDI 番号・音名・セントの変換 |
| `js/judge.js` | 発声練習の判定（記録時間のうち合っていた割合）と、出だし・後半のずれ |
| `js/trace.js` | 発声練習で記録した音程の変化を描くグラフ |
| `js/keyboard.js` | 1 オクターブの鍵盤 |
| `js/settings.js` / `js/storage.js` | 設定と日ごとの記録の保存（localStorage） |
| `js/version.js` / `js/updater.js` | バージョン番号と、新版の確認・更新 |
| `icons/icon.svg` | アイコンの元絵。PNG（`apple-touch-icon.png` 180px、`icon-192.png`、`icon-512.png`）はここから書き出す |
| `manifest.webmanifest` | ホーム画面に追加したときの名前とアイコン |
| `js/voice-session.js` | 発声練習で共有する音声の管理（お手本の再生と、マイクを開く・閉じるタイミング） |
| `js/roll.js` | フレーズ練習の表示（お手本の帯と自分の声の線） |
| `js/modes/voice.js` | 発声練習の入れ物（1音・音程・フレーズの切り替え） |
| `js/modes/mimic.js` | 発声練習の「1音」「音程」 |
| `js/modes/phrase.js` | 発声練習の「フレーズ」 |
| `js/modes/keyboard-quiz.js` | 「音を聞いて鍵盤で答える」クイズの共通部分 |
| `js/modes/relative.js` / `js/modes/absolute.js` | 相対音感・絶対音感モード（問題の作り方だけを持つ） |

### モードを追加するには

1. `js/modes/` に、`id`、`activate()`、`deactivate()` を持つモードを置きます。鍵盤で答えるクイズなら、`createKeyboardQuiz()` に問題の作り方（`makeQuestion`）を渡すだけで作れます。
2. `index.html` の `.mode-switch` にボタンを、練習画面に `<div class="mode" id="mode-<id>">` を足します。
3. `main.js` の `modes` と `RECORD_LABELS` に登録し、`settings.js` の `MODES` に id を足します。
4. `js/updater.js` の `ASSETS` に新しいファイルを書き足します。

記録はモード別に保存されるので、既存の記録とは混ざりません。

## iPhone での注意

- iOS ではマイクを使っている間、Web Audio の音が受話口に回ったり極端に小さくなったりします。そのため、お手本を鳴らす間はマイクを手放して「再生専用」にし、鳴らし終えてからマイクを取り直します。スピーカーの音を自分の声と取り違えることもありません。
- iOS 16.4 以降では、再生専用にすると消音スイッチがオンでも鳴ります。それより古い iOS で音が出ないときは、消音スイッチと音量を確かめてください。
- 設定画面の「テスト音を鳴らす」で、マイクを使わずに音が出るかを確かめられます。
- マイクを一度拒否した場合は、「設定 › Safari › マイク」で許可してからページを再読み込みしてください。
- アプリを裏に回すと、解答中の問題は記録されずに取り消されます。
